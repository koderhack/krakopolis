# Audio

Dźwięk miasta Krakopolis jest **w pełni proceduralny** (Web Audio API) –
nie ma tu zewnętrznych plików `.mp3` / `.ogg`.

Warstwy: ambient miasta, ruch, komunikacja, syreny/alarmy, katastrofa
(ogień / woda / ostrzeżenia). Bez muzyki i bez audio per NPC.

Jeśli kiedyś dodasz nagrania, umieść je tutaj z jasną licencją
(np. CC0 / public domain) i krótką notatką w tym pliku.
